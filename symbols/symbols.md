# symbols.py

符号库管理面板：统一维护 `structure.sty` 中的自定义宏（提取 / 回填 / 删除 / 修改），并同步到各笔记与 TeXStudio 的补全文件 `custom.cwl`。

## 运行

```bash
python symbols.py                   # 进入交互式面板
```

直接运行（不带参数）即进入面板。

## 面板选项

运行后命令行窗口显示：

```
==============================================================
  笔记符号管理面板
==============================================================
  笔记根目录：D:\你的笔记目录
  符号来源　：D:\你的模板目录\Math-Note\structure.sty
  补全文件　：%APPDATA%\texstudio\completion\user\custom.cwl
  子文件夹　：10 个
--------------------------------------------------------------
  1. 设置笔记文件夹并扫描目录结构（记录结构，只更新有差异的部分）
  2. 显示子文件夹结构（按英文名排序编号，可多选查看）
  3. 提取各子文件夹的符号
  4. 回填提取的符号（先 structure.sty，再 custom.cwl）
  5. 检验并管理符号（看引用情况，删除或修改任意符号）
  6. 引入新的记号（选归属子段，自动刷新补全）
  7. 退出
--------------------------------------------------------------
  可多选，用英文逗号分隔（如 1,3,5）
```

### 选项 1：设置笔记文件夹并扫描目录结构

设置笔记根目录，扫描其下的目录结构（有哪些子文件夹、每个含多少文件、有哪些子目录），与上次记录对比后**只更新有差异的部分**。在新环境里第一件事就是跑它。

```
[1] 设置笔记文件夹并扫描目录结构
  请输入笔记文件夹路径（回车保持 D:\你的笔记目录）：  笔记根目录保持：D:\你的笔记目录

  目录结构（11 个子文件夹）：
    [笔记] Note_A
        顶层文件 12 个，子目录 1 个，合计 120 个文件
        Content(110)
    [笔记] Note_B
        顶层文件 12 个，子目录 1 个，合计 40 个文件
        Content(28)
    …
    [非笔记] Archived_Note
        顶层文件 1 个，子目录 1 个，合计 3 个文件
        Content(2)

  目录结构与上次记录一致，无需更新。
  目录结构档案已更新：notes_tree.json
```

- 直接回车保持当前根目录；填入新路径则同时写回 `symbols.conf`。
- `[笔记]` / `[非笔记]` 的判据是该目录下**有没有 `structure.sty`**。
- 统计会跳过隐藏目录（`.git`）、下划线开头的目录（`__pycache__`、`_template_apply_backup_*`）、`ignore` 中列出的名字、备份文件与 LaTeX 编译产物，因此**编译前后不会误报结构变化**。
- 有差异时逐条列出 `[新增]` / `[消失]` / `[变化]`（含文件数增减与具体文件名），并只重写这部分记录。
- 若发现各笔记里有模板还没有的符号，末尾追加一行提示：

  ```
    提示：另有 2 个新符号待提取（\Ext、\Tor），见选项 3
  ```

### 选项 2：显示子文件夹结构

按英文名排序编号列出根目录下的子文件夹，输入编号（可多选）查看其结构详情：顶层文件清单（含字节数）、被忽略的编译产物、递归展开的子文件夹树。**纯查看，不改动任何文件。**

```
[2] 显示子文件夹结构
  笔记根目录：D:\你的笔记目录
    【1】Note_A    [笔记]
    【2】Note_B    [笔记]
    …
    【11】Archived_Note    [非笔记]
  请输入编号（可多选，英文逗号分隔；直接回车返回）：
  ══ Note_A ══
    顶层文件 9 个：
      CHANGELOG.md / commit.md / commit.py / main.tex / quiver.sty
      README.md / setup_mode.md / setup_mode.py / structure.sty
    （另有 1 个编译产物已忽略：main.pdf）
    子文件夹树：
└─ Content/  （110 个文件）
    ├─ 1_Some_Chapter/  （30 个文件）
    ├─ 2_Another_Chapter/  （52 个文件）
    …
```

- 编号按英文名升序，与选项 1 的列出顺序一致。
- 多选写法示例：`1,3,5`，或中文逗号 `1，3`。
- 每个文件夹的文件数已排除忽略项，与选项 1 的统计口径相同。

### 选项 3：提取各子文件夹的符号

比对各笔记的 `structure.sty` 与模板，把「**笔记里有、模板里还没有**」的符号收集进提取档案 `symbols_extract.json`，供选项 4 回填。

典型场景：某本笔记先在自己的 `structure.sty` 里试定义了一个记号，用顺手之后要并入公共模板、让所有笔记都能用。

```
[3] 提取各子文件夹的符号
  [Note_A] 2026-09-21 提取 1 个符号
  已写入提取档案：symbols_extract.json（本次合计 1 条）
```

若各笔记与模板已经一致：

```
[3] 提取各子文件夹的符号
  没有可提取的新符号（各子文件夹与模板一致）。
```

- 只比对 `[模块 VI]` 范围内的定义，模块外的东西不参与。
- 档案结构为 `{子文件夹: {年-月-日: {命令名: 定义行}}}`，同一天重复提取会覆盖当日同名条目。
- 多本笔记给出**同名但定义不同**的新符号时，档案里记的是按笔记名字母序**先遇到的那一份**，脚本不会自动报警——出现这种情况建议先手工统一。
- 本选项只写档案，**不动** `structure.sty`。

### 选项 4：回填提取的符号

把提取档案里的符号写入模板 `structure.sty` 的 `[模块 VI]`，给定义补上来源注释（`提取自 <笔记名>-<年-月-日>`），随后分发到所有笔记并刷新 `custom.cwl`。

```
[4] 回填提取的符号
  已写入模板 structure.sty：新增 1 个，补注来源 0 个
  [已同步] Note_A
  [已同步] Note_C
  已刷新补全：148 个符号 -> %APPDATA%\texstudio\completion\user\custom.cwl
```

若档案为空，会先问一句要不要现在提取：

```
[4] 回填提取的符号
  ! 尚无提取记录。
  是否现在提取各子文件夹的符号？ (Y/N)：  已跳过回填。
```

- 回答 `Y` 会先跑一次选项 3 再继续回填；回答 `N` 直接跳过。
- 已在模板中、且注释已标注过来源的符号不会重复处理，末尾会提示「N 个符号已标注过来源，未重复处理」。
- 回填位置是 `[模块 VI]` 末尾；分发时逐本笔记备份 `structure.sty`。
- 三步（写模板 → 分发 → 刷新补全）在本选项内一次做完，**重启 TeXStudio** 后新符号即可补全。

### 选项 5：检验并管理符号（删除 / 修改）

逐本笔记扫描正文（`main.tex` 与 `Content/` 下全部 `.tex`），统计每个符号的引用次数，列出整份符号库；选中的符号可以删除，也可以就地修改定义。**统计范围含符号源笔记本身**（`template` 所在的那本笔记，它不在分发目标里，但它的正文同样会引用这些符号）。用于清理弃用的记号、订正写错的记号。

```
[5] 检验并管理符号（删除 / 修改）
  共 10 本笔记、148 个符号；其中 22 个未被任何笔记正文引用。
  全部未引用：\B、\BProduit、\BSomme、\CP、…
  各笔记未引用数量：
    [Note_A] 36 个
    [Note_C] 12 个

  符号清单（共 148 个；* = 正文与符号库内部均未引用，† = 仅被符号库内部定义调用）：
     【  1】\N              84 次  \mathbb{N}    % 自然数集
     【  2】\R              63 次  \mathbb{R}    % 实数集
    *【  3】\BProduit        0 次  \operatorname{B}    % 试验用
    †【  4】\bigtwo         0 次  （跨行定义，不在此处修改）    库内 6 处
    …

  输入编号或命令名选择符号（可多选，英文逗号分隔）；直接回车返回：
  > 3, \CP

  对选中的符号：
    \BProduit（正文引用 0 次）
    \CP（正文引用 0 次）
    1. 删除
    2. 修改（定义体 / 参数说明 / 注释）
    0. 取消
  请选择（0/1/2）：
```

- 清单按 `structure.sty` 中的**原始顺序**编号，与 `[模块 VI]` 内的子段分组一致。
- 行首标记：`*` 表示正文与符号库内部都没人引用；`†` 表示正文没引用、但符号库里有别的定义在调用它（行尾注明「库内 N 处」），删掉同样会让那些定义失效。
- 选中后回显的「正文引用 N 次」只算正文；若该符号还被库内定义调用，会一并注明「库内 N 处」，别只看正文的 0 次。
- 选择时**编号与命令名可混用**：`3,5`、`\CP`、`3,\CP` 都行，反斜杠可省。
- 判定用「`\` + 名字 + 后不接字母」，所以 `\B` 与 `\BProduit` 不会互相误判；注释里出现的引用也算「用过」（宁可判为已用）。
- 本选项只管 `[模块 VI]` 里的符号；`[模块 VII]` 及之后的宏不在清单内。

#### 删除

可以删**任意**现有符号，不再要求「所有笔记都没用过」。

删除前会检查两种引用，各列一段警告，最后**共用同一个确认**：

- 正文引用：总次数与具体文件（每个符号最多列出 3 个文件，文件后是该文件里的处数）；
- 符号库内部引用：库内被调用的次数与调用它的定义名（跨行定义里出现的调用也算）。

```
  ! 以下符号仍被正文引用，删除后编译会报 Undefined control sequence：
      \CP  7 次
          Note_A/Content/3_Topology/index.tex  5 处
          Note_C/Content/1_Basics/index.tex  2 处

  ! 以下符号被符号库内部定义引用，删除后这些定义会一起失效：
      \bigop  库内 6 处
          \bigast
          \bigtop
          \bigbot
  确认删除？（正文引用不会被自动清理） (Y/N)：
```

- **正文不会被自动改动**：删除后原引用处会编译报错，需自行清理。
- **删除不可撤销**：`structure.sty` 按已有约定不做 `.bak` 备份（分发会直接覆盖各笔记的同名文件），误删请用各笔记仓库的 git 恢复。
- **调用它的定义也不会被自动改动**：删掉被库内引用的宏后，那些定义要一并改写或删除，否则编译报 `Undefined control sequence`。
- 跨行定义（`\newcommand{\x}[2]{%` 换行续写）会**整块删除**，不会留下孤立的代码残骸。
- 删除后照常分发到各笔记并刷新 `custom.cwl`。

#### 修改

只改选中的符号，其余行原样保留（注释前的对齐空格也保留）。

依次询问定义体、参数说明、注释三项，**回车保持原值，输入 `-` 清空**（定义体不接受清空，`-` 就是字面减号）：

```
  修改 \norm
    当前：\newcommand{\norm}[1]{\left\|#1\right\|}    % 范数
  定义体（回车保持 \left\|#1\right\|）：\left\|#1\right\|_2
  参数说明，如 1；- 表示去掉参数（回车保持 [1]）：
  注释，- 表示清空（回车保持 范数）：范数（2 范数）
    改为：\newcommand{\norm}[1]{\left\|#1\right\|_2}    % 范数（2 范数）
  写入吗？ (Y/N)：
```

- 只替换花括号里的定义体，`\newcommand` / `\renewcommand` 与 `[1]` 参数说明按原样拼回；要改参数个数就在第二问里填。
- **参数说明只接受 1-9**：可写 `2`（会自动补成 `[2]`），也可写 `[2]`、`[2][默认]` 这种完整写法；`a`、`0`、`10`、`[a]` 之类会被拒绝并跳过该符号（LaTeX 只认 1-9 的数字）。
- 定义体不能为空；花括号不配对会被拒绝并跳过该符号。
- **定义体不接受裸 `%`**：`\text{50% 的数}` 会被拒绝，请写成 `\%`。裸 `%` 之后整行都是注释，定义会残缺，而且该行此后连清单都拆不开、只能手改文件。
- 一次选多个符号时逐个询问，最后一次性写模板、分发、刷新补全。
- **跨行定义不支持就地修改**：清单里标为「（跨行定义，不在此处修改）」，这类宏请在编辑器里手工改。
- 修改后 `custom.cwl` 的补全说明同步更新，重启 TeXStudio 生效。
- 注意：尚未写到的章节里打算用的符号也会被判为「未引用」。`*` 只是提示，删除前仍建议看一眼清单。

### 选项 6：引入新的记号

依次输入**命令名**（只允许字母）、**定义**（如 `\operatorname{Orb}`，花括号须配对）、**注释**（可选）后，要求选择归属子段。运行效果：

```
[6] 引入新的记号
  说明：命令名只允许字母；定义不能为空；注释可选。
  命令名（不含反斜杠，必填）：Per
  定义（必填，例如 \operatorname{Orb}）：\operatorname{Per}
  注释（可选，回车跳过）：周期函数群

  归属子段（[模块 VI] 数学符号定义库）：
    1. 6.1 代数
    2. 6.2 几何
    3. 6.3 分析
    4. 新建子段
    0. 不分段，直接追加到 [模块 VI] 末尾
  请选择：3

  已写入模板 [模块 VI]：6.3 分析（段内末尾）
    \newcommand{\Per}{\operatorname{Per}}    % 周期函数群
  已同步到 10 个子文件夹的 structure.sty
  已刷新补全：147 个符号 -> %APPDATA%\texstudio\completion\user\custom.cwl
  提示：重启 TeXStudio 后即可补全（编辑器只在启动时读取补全文件）。
```

- 菜单中的 1–3 项对应 `structure.sty` 中 `[模块 VI]` 内的三个编号子段（`% -------- 6.1 代数 --------` 这类标记行会自动识别）；输入对应数字，新定义即插入该子段末尾，与同类符号排在一起。
- 选 **4. 新建子段**：先问编号（默认按现有最大编号递增，如 `6.4`），再问标题（如 `拓扑`），随后在模块末尾生成新子段标题并写入定义。
- 选 **0**：不建子段，直接追加到 `[模块 VI]` 末尾。
- 若命令名在模板中已存在，会先询问是否覆盖；确认后在**原位置**替换定义，不会产生重复定义。
- **内核同名命令会自动改用 `\renewcommand`**。命令名若属于 LaTeX 内核已有定义（文本重音 `\H` `\i` `\d` `\b`、文本符号 `\P` `\S` `\aa`、内核数学字形 `\Re` `\Im` `\aleph` `\emptyset` `\infty` 等，名单见脚本里的 `LATEX_KERNEL`），生成的定义行会自动写成 `\renewcommand` 并打印一行提示：

  ```
  · 内核已有 \H，自动改用 \renewcommand（\newcommand 会报 already defined）。
  ```

  原因：`\newcommand` 只对**全新**名字合法，对已定义命令会以
  `! LaTeX Error: Command \H already defined.` 中止编译 —— 这是会**中断整本书编译**的错误，
  且首轮看不出来（`\newcommand` 报在 preamble，`exit code` 非 0）。名单只收内核自带的；
  `amssymb` 等**宏包**提供的名字（`\varnothing`、`\square` 之类）不在内，万一撞上，
  把生成的那行手工改成 `\renewcommand` 即可。

### 补全文件的排除名单（`CWL_SKIP`）

少数符号**要留在 `structure.sty` 里，但不写进 `custom.cwl`**。脚本里用 `CWL_SKIP` 控制：

```python
CWL_SKIP = {"H"}
```

命中者照常保留在符号库中、参与分发，只是不会出现在自动生成段里；刷新时会打印
`按 CWL_SKIP 跳过 1 个：H`。目前只排除 `\H` —— 它是内核的匈牙利重音，TeXStudio
**内置补全表**里本就有这一条，再登记成 `\H#m`（数学专用）会与之重复。

写入模板后自动完成「分发到各子文件夹」与「刷新 `custom.cwl`」两步，无需再跑选项 4。

> **写完记得重启 TeXStudio**：编辑器只在启动时读入补全文件，运行期间改动不重载。

## 命令行模式

不带参数时进入面板；带参数则直接执行对应操作（需加 `--write` 才真正写入，否则仅预览）。

| 参数 | 功能 |
|---|---|
| `--all` | 回填 + 刷新补全 + 分发（三项全做） |
| `--merge` | 回填：各笔记 → 模板 |
| `--cwl` | 刷新 TeXStudio 补全 |
| `--distribute` | 分发：模板 → 各笔记 |
| `--drop NAME ...` | 从模板删除指定符号（可跟多个）。删除前会报出正文引用次数与库内调用方，但不拦截 |
| `--write` | 真正写入（不加则仅预览） |
| `--root` / `--template` / `--cwl-path` | 覆盖默认的根目录 / 符号来源 / 补全文件路径 |

例：

```bash
python symbols.py --all --write          # 回填 + 刷新补全 + 分发
python symbols.py --drop alt dr --write  # 删除 \alt 与 \dr
```

> 改动符号库后须用 `--all --write`（而非只 `--distribute`），否则会出现「编译正常但编辑器报未知命令」——因为编译读 `structure.sty`，而编辑器读 `custom.cwl`，两者需同时刷新。
