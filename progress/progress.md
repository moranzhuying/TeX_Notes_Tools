# progress.py — 写作进度追踪表

扫描 LaTeX 笔记的写作进度，在浏览器中查看。设计依据见 `progress_design.md`。

**不联网、不上传、不写笔记目录**：服务只监听 `127.0.0.1`，只读取 tex 文件，标记数据写在脚本同目录。

---

## 运行方式

**直接启动**

```
python progress.py
```

**带参数**

```
python progress.py --rescan             仅扫描并打印统计，不启动服务
python progress.py --report out.md      导出 Markdown 报告到指定文件
python progress.py --port 8766          指定端口
python progress.py --no-browser         启动服务但不自动打开浏览器
```

只依赖 Python 标准库，任何 Python 3.8+ 均可运行，无需安装任何第三方包。

若你另有自己的总入口面板，也可以在其中增加一项调用本脚本；建议采用「调起后立即返回」的方式，让服务在后台运行。

**不做 `.bat`**：Windows 上 `.py` 默认没有文件关联，双击不可靠，命令行入口已够用。

## 界面说明

### 顶栏

| 按钮 | 作用 |
|---|---|
| 刷新 | 重新全量扫描（约 1.2 秒） |
| 报告 | 下载 Markdown 进度报告 |
| 主题 | 亮色 / 暗色切换（记住选择） |
| 退出 | 停止服务（页面随后显示「服务已停止」） |

顶栏左侧显示服务状态与上次扫描时间。

### 总览页

自上而下：

1. **续写入口** —— 「设为下一步」的节（最多 2 条）、最近改动的 6 个文件、停滞提醒。点任一条目直接用 TeXStudio 打开该文件。
2. **全库合计卡** —— 整体进度、规划小节、已写、待补、定理环境，附三段式进度条。
3. **笔记卡片** —— 每本一张，含进度条、百分比、已写/规划数、定理环境数、总字数，以及「未编译章数」「未启用章数」「待补数」标记。点卡片跳到该笔记的明细页。
4. **排序** —— 默认按最近改动，可切换按名称。

### 明细页

- **顶部** —— 笔记切换、状态筛选（全部 / 已写 / 未写 / 未建 / 待补）、搜索框，以及两个开关：**「编辑范围」**（显示行尾复选框）与**「未启用章」**（是否在树中一并显示未启用的章，默认开）。
- **左侧树** —— 层级不固定（有的笔记两层，有的三层），手风琴式展开，默认展开当前笔记中最近改动的那一章。
  - **未启用的章默认也进树** —— 灰显并在章名后标「未启用」，其下的节、小节照常可展开、可点开、可标记，只是不计入进度统计。点「未启用章」按钮可把这类章从树中收起，只看计入范围。
  - **「未编译」标签** —— 索引里被 `%` 注释掉的节 / 小节照常进树（否则它下面挂的整块内容会凭空消失）：有已写内容的计入统计并标「未编译」，整枝全空的归入「未启用」。
  - **计入 / 排除用「编辑范围」按钮切换** —— 平时不显示复选框，点工具栏的「编辑范围」后才在每行**最右**出现。勾选表示计入进度统计；取消勾选则该节点**连同其下的章、节、小节一并排除**（父节点被排除时子树继承）。被排除的条目会灰显但仍留在原位，可随时重新勾选。若排除的是顶层章，它会被归入页面底部的「未启用章节」分组，在那里点「计入」即可恢复。
  - **行内进度条** —— 章 / 节行显示三段式（已写 / 空壳 / 未建）；小节行显示三个维度（环境 / 正文 / 证明）的完成情况，蓝为已完成、橙为待补。
  - **节点显示名**：节目录取 `\chapter{...}`（本笔记体系的写法约定：`\chapter` 写在小节文件里、代表所属节目录；也有节目录把内容直接写在自身 `index.tex` 里，同样能取到），小节取 `\section{...}`；未填标题时回退为去掉编号前缀、下划线转空格的目录名 / 文件名。
  - **编号按笔记的完整结构**：部分号用中文数字（`第一部分：……`），章号在全书内递增（`1`、`2`…），节号为「章号.节内序号」（`1.1`、`1.2`…）。被 `main.tex` 注释掉的 `\input` **同样参与编号** —— 编号要反映**笔记的章节结构**，而不是编译产物：若按编译结果编号，被注释掉的首章会拿不到编号，后面各章整体前移，与作者对结构的认知相悖。是否纳入编译另由「未编译」标注体现。
  - 目录行：编号 + 显示名 + 子项数 + 已写/规划数
  - 小节行：状态点 + 编号 + 显示名 + 行尾三个标记
- **右侧详情面板** —— 三个维度标记、统计数字、**环境构成**（只列出实际出现过的环境，按数量降序，如「命题 12 个、定义 5 个」，没有的环境不显示）、「值得留意」提示、备注、待办、操作按钮。面板底部有**图例**，说明行首三个状态点（蓝 = 已写、灰实心 = 文件已建但内容为空、灰空心 = 索引已规划但文件未建）与行尾三个标记（环境 / 正文 / 证明；灰勾为已完成、橙圈为待补）的含义。
- **底部** —— 默认折叠的两个分组：
  - 「未启用章节（N）」：列出章名、小节数、排除原因，点「计入」即可整章纳入统计。
  - 「未纳入索引的文件（N）」：既没写进 `index.tex`、也没以注释形式出现的游离 `.tex`。它们不属于笔记结构，所以不进树；列在这里是为了不被误认为「工作台没显示全」。多为写到一半还没挂进索引的小节，或改名后忘删的旧文件。

### 三种颜色

| 颜色 | 含义 |
|---|---|
| 蓝 | 已写 |
| 中灰 | 已建文件但内容为空 |
| 深灰 | 索引中已规划、文件尚未创建 |
| 橙 | 唯一的暖色，只用于「待补」标记 |

## 三维标记

每个小节有三个可点击的标记，**默认全部为「已完成」**：

| 维度 | 含义 |
|---|---|
| 环境 | 该节的定理环境是否写完 |
| 正文 | 该节的陈述性文字是否写完 |
| 证明 | 该节的 proof / sketch 是否写完 |

- 点击灰勾 → 变为橙色空心圈（待补），再点切回。
- 笔记卡片与续写区会汇总显示待补数。
- **「证明」维度支持批量**：在详情面板可把整章无 proof/sketch 的小节一次标为待补。

备注与待办是两块独立区域：备注是自由文本（说明用），待办是可勾选的条目（动作用）。**备注不参与进度计算。**

## 配置文件 `progress.conf`

首次运行自动生成。改后需重启服务。

| 段 | 键 | 说明 |
|---|---|---|
| `[paths]` | `root` | 笔记工作区根目录，留空则用脚本所在目录 |
| | `texstudio` | TeXStudio 可执行文件路径，留空则自动探测（先查注册表，再查常见位置） |
| `[server]` | `host` | 监听地址，默认 `127.0.0.1`（仅本机可访问） |
| | `port` | 端口，默认 `8765`，被占用时自动顺延（最多试 10 个） |
| | `auto_open` | 启动后是否自动打开浏览器 |
| `[scan]` | `ignore` | 额外忽略的目录名，逗号分隔 |
| | `min_chars` | 判定「有内容」的字符阈值，默认 50 |
| | `stagnant_days` | 停滞提醒的阈值天数，默认 14 |
| | `recent_count` | 续写区显示的最近改动文件数，默认 6 |

## 数据文件 `progress_marks.json`

存放三维标记、备注、待办、计划标记与章统计覆盖。

- **原子写入**：先写临时文件再替换，防止写一半中断导致损坏。
- **自动备份**：每次写入前把旧文件存为 `progress_marks.json.bak`。
- **损坏恢复**：启动时校验，损坏则从 `.bak` 恢复并提示。
- 导入导出按时间戳合并，不丢任一侧记录。

想重置全部标记，删掉这个文件即可。

## 行为细节

### 扫描口径

- 从每本笔记的 `main.tex` 出发，**递归解析 `\input` 树**，不假设目录层级。
- `\input` 路径解析做花括号配对（路径可能含 `R^{n}` 这类花括号），并在不以 `.tex` 结尾时补上扩展名。**不能照 `Path.suffix` 判断是否已有扩展名** —— 文件名本身可能含点（如 `1_The_complexes_Ku,_K.u,_C,_Ku,_C`），那样后缀会算成 `.u,_C,_Ku,_C`，漏补 `.tex`，真实存在的文件被误判成「未建」。
- `main.tex` 与各级 `index.tex` 里**被 `%` 注释掉的 `\input` 同样建树**（标为未纳入编译），否则它下面挂的节 / 小节会整块消失。是否计入另由「章的计入规则」判定。
- **有内容**的判定：剔除空行、`%` 注释、章节标题行、`\input` 行后，剩余字符数 > `min_chars`。
- 既没写进 `index.tex`、也没以注释形式出现的 `.tex` 不进树，但会列在明细页底部的「未纳入索引的文件」分组里。
- 统计 17 个定理环境（`definition`/`theorem`/`proposition` 等），`enumerate`、`align*`、`tikzcd` 等排版环境视为内容、不计入环境数。
- 全量扫描数千个 tex 文件约需 1–2 秒，因此每次刷新都直接重扫，不做缓存。

### 章的计入规则

按「未纳入编译」与「有无内容」两个维度判定：

| 未纳入编译 | 有已写内容 | 处理 |
|---|---|---|
| 否 | 有 | 计入 |
| 否 | 无 | 计入（占分母，待写） |
| 是 | 有 | 计入，标注「未编译」 |
| 是 | 无 | 排除，不计入进度 |

被排除的章在明细页底部的「未启用章节」分组中可见，其下的小节也会在树里灰显列出（不计入统计）。

**同一套四象限按层级递归适用**：各级 `index.tex` 里被注释掉的节 / 小节也照此判定 —— 有内容则计入并标「未编译」，整枝全空则归入「未启用」。

**手动覆盖自动**：每章可设为「自动 / 强制计入 / 强制排除」，手动设置过的章会显示「手动」标记。

需要手动的原因：自动统计会出错。例如某本习题集的章节索引只引用了 2 个文件，于是算出 100%，而实际有 247 个文件。

### 打开文件

点击「用 TeXStudio 打开」或续写区的条目，由服务端调用 TeXStudio 打开。

- 只允许打开工作区内的文件（越界请求被拒绝）。
- TeXStudio 路径自动探测：先读注册表 `.tex` 的关联程序，再查常见安装位置。

### 提示规则

**硬提示**（确定的问题，红色小点）：`\begin` 与 `\end` 不配对；环境内容为空。

**软提示**（值得看一眼，琥珀色小点）：环境数明显少于同节其他小节；同节其他小节都有 proof/sketch 而本节没有；同节其他小节都有陈述文字而本节为零。

软提示**只做相对比较**（与同一节内的其他小节比），不用绝对阈值——否则几乎每节都会亮灯。

### 快捷键

| 键 | 作用 |
|---|---|
| `/` | 切到明细页并聚焦搜索框 |
| `Esc` | 收起详情面板（在输入框中则取消聚焦） |

### 目录改名的处理

标记会**按内容指纹自动迁移**：文件名唯一时按文件名匹配，重名时按内容指纹匹配。匹配不到的保留记录并标为失效，不自动删除。
