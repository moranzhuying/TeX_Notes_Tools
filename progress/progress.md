# progress.py — 写作进度追踪表

扫描 LaTeX 笔记的写作进度，在浏览器中查看。设计依据见 `progress_design.md`。

**不联网、不上传、不写笔记目录**：服务只监听 `127.0.0.1`，只读取 tex 文件，标记数据写在脚本同目录。

---

## 运行方式

**直接启动**

```
python progress.py
```

**带参数**

```
python progress.py --rescan             仅扫描并打印统计，不启动服务
python progress.py --report out.md      导出 Markdown 报告到指定文件
python progress.py --port 8766          指定端口
python progress.py --no-browser         启动服务但不自动打开浏览器
```

只依赖 Python 标准库，任何 Python 3.8+ 均可运行，无需安装任何第三方包。

若你另有自己的总入口面板，也可以在其中增加一项调用本脚本；建议采用「调起后立即返回」的方式，让服务在后台运行。

**不做 `.bat`**：Windows 上 `.py` 默认没有文件关联，双击不可靠，命令行入口已够用。

## 界面说明

左侧导航五页：**总览** / **明细** / **欠账** / **统计** / **设置**。

### 顶栏

| 按钮 | 作用 |
|---|---|
| 刷新 | 重新全量扫描（约 1.2 秒） |
| 报告 | 下载 Markdown 进度报告 |
| 主题 | 亮色 / 暗色切换（记住选择） |
| 退出 | 停止服务（页面随后显示「服务已停止」） |

顶栏左侧显示服务状态与上次扫描时间。

### 总览页

自上而下：

1. **续写入口** —— 顶部是**欠账清单入口**（「共 N 条 →」，点进欠账页）；下面是「设为下一步」的节（最多 2 条）、最近改动的 6 个文件、停滞提醒。点续写区的条目直接用 TeXStudio 打开该文件。
   - 「最近改动」按文件修改时间排，所以**打开过**或**只顺手改了一下**的文件也会进来。旁边有「**清除**」：把当前这一批当作已看过，腾出屏幕；之后再有新的改动照样会重新出现（不是永久关掉这个区块）。清除状态记在本浏览器里。
   - 本页只做**速览**，不在这里做精细筛选与处理。
2. **全库合计卡** —— 整体进度、规划小节、已写、确认完成、待补、定理环境，附三段式进度条。
3. **笔记卡片** —— 每本一张，含进度条、百分比、已写/规划数、确认完成率、定理环境数、总字数，以及「未编译」「未启用」「待补」「整章待补」标记（前两项的用词随笔记的层级模式变成「章」或「部分」）。点卡片跳到该笔记的明细页。
4. **排序** —— 默认按最近改动，可切换按名称。

### 明细页

- **顶部** —— 笔记切换、状态筛选（全部 / 已写 / 未写 / 未建 / 待补 / 可疑）、搜索框，以及两个开关：**「编辑范围」**（显示行尾复选框）与**「未启用章」**（是否在树中一并显示未启用的顶层节点，默认开；按钮文案随笔记的层级模式变成「未启用部分」）。两个开关与层级模式都会记住。
  - **笔记切换是自适应的**：笔记不多（≤ 12 本）时平铺成一排按钮 —— 标题一眼看全、切换一次点击；更多时自动收成一个下拉 ＋「‹ ›」前后切换（下拉是原生控件，可直接输入标题首字跳转），工具栏不会被标题撑爆。切换后自动展开该笔记里最近改动的那一章。
  - **搜索** —— 空格分隔多个关键字，**全部命中**才显示（`张量积 模` 会列出标题里同时含这两个词的小节）；命中处在标题里高亮，沿途目录自动展开，搜索框右侧显示「命中 N 节」（无结果时提示「无匹配」）。清空搜索后，搜索期间展开的目录会保留，方便接着看上下文。
  - **搜索范围** —— 搜索框右侧的「仅标题 / 标题+正文」：选「标题+正文」时连**文件内容**一起查（跨全部笔记），命中的小节行尾标出「正文 N」（命中处数），右侧面板切换为按笔记分组的**命中清单**（含行号与命中处附近的片段）。选择会记住。
  - **源码 / PDF 预览** —— 点命中清单里的任一条，打开**全屏预览层**：左边是该小节命中行附近的**源码**（行号、命中行加底纹、关键词高亮），右边是**该笔记的 PDF** 并自动跳到命中页。顶部可切「并排 / 只看源码 / 只看 PDF」，也可「用 TeXStudio 打开」或「新标签打开 PDF」；Esc 或「关闭」退出。
- **左侧树** —— 手风琴式展开，默认展开当前笔记中最近改动的那一章。
  - **树的层级与编号按该笔记的「层级模式」渲染**（见下面的「设置页」）：每一层对应哪个 LaTeX 标题命令决定了标题从哪取、怎么编号。默认「自动识别」，一般不用人管。
  - **未启用的章默认也进树** —— 灰显并在章名后标「未启用」，其下的节、小节照常可展开、可点开、可标记，只是不计入进度统计。点工具栏按钮可把这类章从树中收起，只看计入范围。
  - **「未编译」标签** —— 索引里被 `%` 注释掉的节 / 小节照常进树（否则它下面挂的整块内容会凭空消失）：有已写内容的计入统计并标「未编译」，整枝全空的归入「未启用」。
  - **计入 / 排除用「编辑范围」按钮切换** —— 平时不显示复选框，点工具栏的「编辑范围」后才在每行**最右**出现。勾选表示计入进度统计；取消勾选则该节点**连同其下的章、节、小节一并排除**（父节点被排除时子树继承）。被排除的条目会灰显但仍留在原位，可随时重新勾选。若排除的是顶层节点，它会被归入页面底部的「未启用」分组，在那里点「计入」即可恢复。
  - **行内进度条** —— 目录行显示三段式（已写 / 空壳 / 未建）；小节行显示三个维度（环境 / 正文 / 证明）的完成情况，蓝为已完成、橙为待补。
  - **行内提示点** —— 小节行尾的小圆点：红＝硬提示（编译层面确定的问题，如 `\begin` 未配对、空环境），琥珀＝软提示（与同一节的其他小节相比明显偏少）。悬停显示具体原因；工具栏筛选「可疑」可只看这类小节。
  - **章行上的小旗** —— 章 / 节行尾的小旗是「整章待补」的手动标记，点一下切换，与小节级的待补汇总并存、语义不同（用于不好归到某一节的问题）。小节行尾另有两处小标记：便签图标表示该节有备注，橙色数字表示还剩几条待办没勾。
  - **目录节点也能点开** —— 点章 / 节行既展开它，也把该节点设为选中，右侧显示它的详情（见下）。
  - **节点显示名**：顶层（章 / 部分）取 `main.tex` 里该 `\input` 上方的 `\chapter{...}` / `\part{...}`；目录取自身或子树里第一个属于该层的标题（如 `\section{...}`）；叶子取自己文件里属于该层的标题（如 `\subsection{...}`）；附录取 `\appendixchapter` / `\appendixsubsection`。未填标题时回退为去掉编号前缀、下划线转空格的目录名 / 文件名。
  - **编号按笔记的完整结构**（与层级模式对应）：顶层是「章」时写成 `第1章：…`，其下为 `1.1`、`1.1.2`；顶层是「部分」时写成 `第一部分：…`（中文数字，部分不占章号）；附录走自己的计数器，显示成 `附录 A：…`、`A.1`。被 `main.tex` 注释掉的 `\input` **同样参与编号** —— 编号要反映**笔记的章节结构**，而不是编译产物：若按编译结果编号，被注释掉的首章会拿不到编号，后面各章整体前移，与作者对结构的认知相悖。是否纳入编译另由「未编译」标注体现。
  - 目录行：编号 + 显示名 + 子项数 + 已写/规划数 + 整章待补小旗
  - 小节行：状态点 + 编号 + 显示名 + 行尾三个标记 + 提示点 + 备注 / 待办小标记
- **右侧详情面板** —— 按选中的是「章 / 节」还是「小节」给出不同内容：
  - 点**小节**：三个维度标记、统计数字、**环境构成**（只列出实际出现过的环境，按数量降序，如「命题 12 个、定义 5 个」，没有的环境不显示）、「值得留意」、备注、待办，以及「用 TeXStudio 打开」「设为下一步」。
  - 点**章 / 节**：小节数、已写 / 规划、定理环境、字数、最后修改，另有三个操作 —— 「整章待补」的切换、把该层下「已写但既无 proof 也无 sketch」的小节**批量**标为证明待补、以及「计入范围」（自动判定 / 强制计入 / 强制排除）。
  - 「值得留意」由服务端在扫描时算好：硬提示看单个文件即可确定；软提示只在**同一节内的各小节之间**横向比较（比中位数、比是否全都有），不用绝对阈值 —— 正文以外的文字占比本就低，按绝对阈值判断会让几乎每一节都亮灯。
  - 面板底部有**图例**，说明行首三个状态点（蓝 = 已写、灰实心 = 文件已建但内容为空、灰空心 = 索引已规划但文件未建）、行尾三个标记（环境 / 正文 / 证明；灰勾为已完成、橙圈为待补）、两个提示点与整章待补小旗的含义。
- **底部** —— 默认折叠的两个分组：
  - 「未启用章（N）」：列出顶层节点名、小节数、排除原因，点「计入」即可整章纳入统计。
  - 「未纳入索引的文件（N）」：既没写进 `index.tex`、也没以注释形式出现的游离 `.tex`。它们不属于笔记结构，所以不进树；列在这里是为了不被误认为「工作台没显示全」。多为写到一半还没挂进索引的小节，或改名后忘删的旧文件。

### 欠账页

把所有「还没弄利索」的地方汇总成一份可筛、可排、可就地处理的清单。

**术语**：「欠账」是伞形概念，涵盖四类来源，但不等同于其中任何一类；「待补」特指三维标记（环境 / 正文 / 证明）里有待补的维度。

| 来源标签 | 含义 |
|---|---|
| 待补 | 三维标记中至少一项标为待补 |
| 待办 | 该小节待办清单里尚未勾选的条目 |
| 下一步 | 被「设为下一步」的小节 |
| 整章待补 | 章 / 节上的手动标记（不好归到某一节的问题） |

只统计**计入范围内**的条目 —— 与明细页的统计口径一致。

- **工具栏** —— 来源多选（默认全选）、笔记筛选（全部 / 单本）、排序（默认「最久未动在前」，另可切「章节顺序」）、右侧「共 N 条」（筛选掉条目时另标「全部 N 条」）。
- **清单行** —— `笔记 › 章 › 节`面包屑 + 来源标签 + 内容 + 停滞天数。停滞天数按「扫描时刻 − 该节点最后修改」算，超过配置的阈值天数时用橙色标出。
- **点标题/面包屑** —— 跳到明细页、展开沿途目录并选中该节点（从欠账直接回到结构位置）。
- **行内动作**（欠账的唯一写入口）：

  | 行类型 | 动作 |
  |---|---|
  | 待补 | 三个维度的小标记，点一下把该维度切回「已完成」 |
  | 待办 | 勾选完成 |
  | 下一步 | 取消下一步 |
  | 整章待补 | 取消整章待补（只有这一个动作） |

- **待补按小节合并成一行**（列出哪几维待补），待办按条目分行。
- 无欠账或筛选后为空时给出空态提示，并区分「全库无欠账」与「当前筛选下没有条目」。

### 统计页

四张图，**范围**可在「全库 / 单本笔记」之间切换：全库时 x 轴单位是笔记，单本时是该笔记的章。图表全部手写绘制（本工具不联网、不引外部资源）。

| 图 | 读法 |
|---|---|
| **状态构成** | 每单位一条三段式长条：已写 / 空壳 / 未建，按规划小节数归一；右侧给「已写 / 规划」与完成率 |
| **结构折线** | 沿 x 轴看结构的疏密，三条序列可切：平均每节环境数、正文占比、平均每节字数。分母是**已写小节数** |
| **欠账来源** | 每单位一条：待补 / 待办 / 整章待补 三类计数；「下一步」用蓝色另列（它是主动计划，不是欠账）。与欠账页同一个汇总口径 |
| **定理环境构成** | 环形图，只标前 5 类，其余并入「其他」；只统计计入范围内的章 |

- 折线的三条序列**一次只显示一条**，点按钮切换。
- **折线的横轴**只写短标签（章是「第N章」），完整标题列在**图下方的清单**里；没有数据的单位在那份清单里标「无数据」。轴上每个单位都占固定宽度，图放不下时可**左右滚动** —— 所以标签不会被裁掉，也不会为了塞下标签而隔一个跳一个。
- **折线在缺口处断开**：没有数据的单位不画点，也不跨过它连线（连线会暗示一段并不存在的趋势）。
- **鼠标移到折线图上任意位置**（不必对准圆点）会显示该单位的**完整标题与具体数值**，并给出一条竖向指示线。
- 全库范围的数字取各笔记的进度统计口径（与笔记卡片一致），单本范围取各章的子树汇总口径（与明细页的树、详情面板一致）。
- 「定理环境构成」的名称与数字相邻，只标前 5 类，其余并入「其他」。

### 设置页

左侧导航的第三项。三块：

**显示**

| 项 | 说明 |
|---|---|
| 明细页默认显示未启用的章 | 开（默认）：树上把未启用的顶层节点一并列出，灰显、不计入统计，其下小节照常可展开可标记；关：树里只显示计入范围内的条目。与明细页工具栏上那个按钮是同一项设置。 |

**笔记层级模式**

按笔记分别设置：每本一行，下拉选择该笔记的层级模式。它决定树上每一层对应哪个 LaTeX 标题命令 ——
标题从哪个命令取（`\chapter` / `\section` / `\subsection`）、怎么编号（`1.1`、`1.1.2`、`附录 A`、`A.1`）都由它决定。

| 列 | 含义 |
|---|---|
| 笔记 | 笔记名与目录名 |
| 层级模式 | 下拉：`自动识别` ＋ 各预设（与「新建大纲」是同一套：`textbook` / `textbook-part` / `two-level` / `article` / `grouped`）＋ 以 `\part` 开头的 `部分-章-节` 序列 |
| 依据 | 标「自动」或「指定」，并给出自动识别的依据（`main.tex` 用哪个命令、树几层 → 判定结果） |
| （操作） | 手动指定过的笔记可点「恢复自动识别」；有手动项时底部另有「全部恢复自动识别」 |

「自动识别」取最外层命令于 `main.tex`，其余按 LaTeX 章节命令的次序顺延到**树的层数**（例如 `main.tex` 用 `\chapter`、树三层 → `chapter, section, subsection`）。改动后**立即重扫**（约 2 秒）。

**数据文件**

- 设置写在 `progress_settings.json`，三维标记 / 备注 / 待办 / 章级设置写在 `progress_marks.json`，两者与本工具同目录、彼此分开存放；删掉即恢复默认。
- **导出标记数据 / 导入标记数据** —— 导出下载一份 `progress-marks-<时间戳>.json`；导入按 `updated` 时间戳合并：较新的一份覆盖冲突项，只有一侧有的记录一律保留，不会丢掉任何一边的标记。

### 三种颜色

| 颜色 | 含义 |
|---|---|
| 蓝 | 已写 |
| 中灰 | 已建文件但内容为空 |
| 深灰 | 索引中已规划、文件尚未创建 |
| 橙 | 唯一的暖色，只用于「待补」标记 |

## 三维标记

每个小节有三个可点击的标记，**默认全部为「已完成」**：

| 维度 | 含义 |
|---|---|
| 环境 | 该节的定理环境是否写完 |
| 正文 | 该节的陈述性文字是否写完 |
| 证明 | 该节的 proof / sketch 是否写完 |

- 点击灰勾 → 变为橙色空心圈（待补），再点切回。
- 笔记卡片与续写区会汇总显示待补数。
- **「证明」维度支持批量**：在**章 / 节节点的详情面板**里，可把该层下「已写、但既无 proof 也无 sketch」的小节一次标为证明待补。
- **章级标记「整章待补」**（独立于三维标记）：挂在章 / 节行上的手动标记，与小节级的待补汇总并存、语义不同 —— 用于不好归到某一节的问题。行内小旗点一下切换，章 / 节详情面板里也有同样的按钮。

备注与待办是两块独立区域：备注是自由文本（说明用），待办是可勾选的条目（动作用）。**备注不参与进度计算。**

**两个百分比**（总览页的合计卡与每张笔记卡片都显示）：

| 指标 | 口径 |
|---|---|
| 结构进度 | 已写小节 ÷ 计划小节 —— 只看「有没有写」。 |
| 确认完成率 | （已写小节 − 被标为待补的小节）÷ 计划小节 —— 把你自己标过待补的部分扣掉，用来区分「写完了」与「写完但还欠着」。 |

## 数据文件 `progress_marks.json`

存放三维标记、备注、待办、计划标记、章统计覆盖与章级标记。

- `nodes` 里的每条记录含两个可选字段：`mode`（`auto` / `force_include` / `force_exclude`，计入范围）与 `chapter_mark`（整章待补）。

- **原子写入**：先写临时文件再替换，防止写一半中断导致损坏。
- **自动备份**：每次写入前把旧文件存为 `progress_marks.json.bak`。
- **损坏恢复**：启动时校验，损坏则从 `.bak` 恢复并提示。
- 导入导出按时间戳合并，不丢任一侧记录。

想重置全部标记，删掉这个文件即可。

## 设置文件 `progress_settings.json`

存放设置页里的内容：各笔记的层级模式、显示开关。首次改动设置时才生成。

```json
{
  "version": 1,
  "updated": "2026-09-24T15:02:11",
  "show_unused": true,
  "note_levels": { "Note_B": "part,chapter,section" }
}
```

- `show_unused`：明细页是否默认显示未启用的顶层节点。
- `note_levels`：键是**笔记目录名**，值是层级模式的命令序列；没写的笔记按结构自动识别。
- 同样原子写入 + `.bak` 备份；删掉文件即恢复全部默认（所有笔记回到「自动识别」）。
- 也可以直接编辑这个文件（改完刷新页面即可，无需重启服务）。

## 行为细节

### 扫描口径

- 从每本笔记的 `main.tex` 出发，**递归解析 `\input` 树**，不假设目录层级。
- `\input` 路径解析做花括号配对（路径可能含 `R^{n}` 这类花括号），并在不以 `.tex` 结尾时补上扩展名。**不能照 `Path.suffix` 判断是否已有扩展名** —— 文件名本身可能含点（如 `1_The_complexes_Ku,_K.u,_C,_Ku,_C`），那样后缀会算成 `.u,_C,_Ku,_C`，漏补 `.tex`，真实存在的文件被误判成「未建」。
- `main.tex` 与各级 `index.tex` 里**被 `%` 注释掉的 `\input` 同样建树**（标为未纳入编译），否则它下面挂的节 / 小节会整块消失。是否计入另由「章的计入规则」判定。
- **有内容**的判定：剔除空行、`%` 注释、章节标题行、`\input` 行后，剩余字符数 > `min_chars`。
- 既没写进 `index.tex`、也没以注释形式出现的 `.tex` 不进树，但会列在明细页底部的「未纳入索引的文件」分组里。
- 统计 17 个定理环境（`definition`/`theorem`/`proposition` 等），`enumerate`、`align*`、`tikzcd` 等排版环境视为内容、不计入环境数。
- 全量扫描数千个 tex 文件约需 1–2 秒，因此每次刷新都直接重扫，不做缓存。

### 章的计入规则

按「未纳入编译」与「有无内容」两个维度判定：

| 未纳入编译 | 有已写内容 | 处理 |
|---|---|---|
| 否 | 有 | 计入 |
| 否 | 无 | 计入（占分母，待写） |
| 是 | 有 | 计入，标注「未编译」 |
| 是 | 无 | 排除，不计入进度 |

被排除的章在明细页底部的「未启用章节」分组中可见，其下的小节也会在树里灰显列出（不计入统计）。

**同一套四象限按层级递归适用**：各级 `index.tex` 里被注释掉的节 / 小节也照此判定 —— 有内容则计入并标「未编译」，整枝全空则归入「未启用」。

**手动覆盖自动**：每章可设为「自动 / 强制计入 / 强制排除」，手动设置过的章会显示「手动」标记。

需要手动的原因：自动统计会出错。例如某本习题集的章节索引只引用了 2 个文件，于是算出 100%，而实际有 247 个文件。

### 打开文件

点击「用 TeXStudio 打开」或续写区的条目，由服务端调用 TeXStudio 打开。

- 只允许打开工作区内的文件（越界请求被拒绝）。
- TeXStudio 路径自动探测：先读注册表 `.tex` 的关联程序，再查常见安装位置。

### 提示规则

提示在**扫描时由服务端算好**（前端只负责显示），分两级：

**硬提示**（确定的问题，红色小点）：`\begin` 与 `\end` 不配对（编译必然报错）；环境内容为空（< 20 字符）。

**软提示**（值得看一眼，琥珀色小点）：环境数不到同节其他小节中位数的 1/3；同节其他小节都有 proof / sketch 而本节没有；同节其他小节都有陈述文字而本节为零。

- 软提示**只做相对比较**（与同一节内的其他小节比），不用绝对阈值——否则几乎每节都会亮灯。同节其他小节少于 2 个（或本节尚未写出内容）时不比较。
- 呈现三处：行尾小圆点（悬停看原因）、详情面板「值得留意」、工具栏筛选「可疑」。

### 导出的报告

`--report FILE` 与顶栏「报告」按钮是同一份 Markdown，依次包含：全库概况（含确认完成率、整章待补、值得留意数）→ 各笔记进度表（含确认完成率）→ 待补清单 → 整章待补 → 值得留意 → 未启用章节。

### 正文检索与 PDF 定位

- **正文检索**：扫描时就把读到的 tex 原文留在内存里，检索因此是内存操作、几乎瞬时。词间是 **AND**（同一文件里都出现过即命中，可以在不同行）；范围是**树上的文件**（游离文件不属于笔记结构，不进结果），跨全部笔记，结果按笔记分组。
- **命中片段**：优先给「同一行内全部命中」的行，没有这样的行时退回含第一个词的行；每条给出行号与命中处前后各 60 字符。
- **PDF 定位**：用 `pdftotext`（TeXLive 自带）抽出 PDF 的每页文本，两边都去掉空白再比 —— PDF 文本层里的中文常被插入空格或换行。命中页里**默认跳转页取最长连续段的第一页**：正文讨论某个主题通常连着几页，目录页则是孤立的一两页，这样能避开目录。
- 页文本按「文件 + 修改时间」缓存，同一份 PDF 只抽一次；PDF 重新编译后会自动重抽。
- **PDF 与源码可能不同步**：PDF 是编译产物，源码改了没重编译时两者不一致 —— 预览层底部会标出 PDF 的编译时间，以源码为准。要精确定位到词，在 PDF 里按 Ctrl+F（本工具只能定位到页）。
- 找不到 `pdftotext`、或该笔记目录下没有 `main.pdf` 时，预览层照常显示源码，底部会说明原因。

### 目录改名的处理

标记会**按内容指纹自动迁移**：文件名唯一时按文件名匹配，重名时按内容指纹匹配。匹配不到的保留记录并标为失效，不自动删除。
