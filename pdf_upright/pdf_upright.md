# pdf_upright.py

把「横版幻灯片被打印成 A4 纵向、内容整体转了 90°」的 PDF 转正成横向页面。

针对的坏文件是这一种：页面为纵向 A4，内容是一张竖向位图铺满全页，而页面属性 `/Rotate` 仍是 0，于是阅读器不会自动纠正。修复不重新编码位图：把 90° 旋转烘进内容流，页面框换成幻灯片自身的大小，`/Rotate` 归 0。

## 用法

```bash
python pdf_upright.py                     # 交互面板
python pdf_upright.py <文件或目录> ...      # 预检 + 修复
python pdf_upright.py <目录> --dry         # 只报告，不写文件
python pdf_upright.py <目录> -o <输出目录>  # 不动原件，输出到别处
python pdf_upright.py <目录> -r            # 连子目录一起找
python pdf_upright.py <目录> --ccw         # 内容躺反了，按逆时针 90° 转正
python pdf_upright.py <目录> --yes         # 不再确认
```

总面板选项 15。

面板先问目录（也可直接给一份 PDF，回车用当前目录，`q` 退出），再列出其中的 PDF 并编号。按键：`a` 全部、`1`／`1,3`／`2-4` 选序号、`r` 切换含子目录、`o` 换输出目录、`d` 切换转向、回车换目录、`q` 退出。

## 判定与转换

逐页判断是否属于「横躺」：页面为纵向、无文字层、页面上最大的图像高大于宽、且该图像面积占页面 40% 以上。四条都满足才转；其余页原样保留。

转正后页面尺寸变为幻灯片的宽高（通常 16:9 横向），四周白边随之消失；图像数据原样搬过去，体积与原件接近。

## 就地覆盖与备份

默认就地覆盖原文件。覆盖前：

1. 把原件复制到系统临时目录下的 `pdf_upright_backup-<时间戳>/`（同一秒多次运行会加 `-2`、`-3` 后缀）；
2. 先写到同目录的 `<文件名>.upright.tmp`，成功后原子替换回原文件。

结束时打印备份目录，需要时可从那里取回原件。给了 `-o <目录>` 时原件不动，结果写到该目录。

## 依赖

需要 PyMuPDF。当前解释器没有时，脚本会按 `PDF_UPRIGHT_PYTHON` 环境变量、自身解释器、`python3`／`python`／`py`、以及用户目录下常见虚拟环境的顺序，找一个装了它的解释器重跑；都找不到则提示安装并返回 `2`。

## 退出码

`0` 正常；`1` 没给输入或没找到 PDF；`2` 缺 PyMuPDF。

## 注意事项

- 判定只看形状，**分不出内容往哪边躺**：默认按顺时针 90° 转正，转出来倒立就加 `--ccw`（面板按键 `d`）。原件已备份，可放心重试。
- 已转正的页（横向页、有文字层、非整页贴图）逐页跳过，重复运行不会二次旋转。
- 递归扫描时跳过名为 `横向版` 的子目录，避免把历史副本当输入。
- 改的是页面几何，不动内容：带文字层的 PDF、真正的横版原稿都不会被改动。
- 面板里直接给单份 PDF 时不再二次确认，选中即转；给目录时同理，用编号选过就执行。
