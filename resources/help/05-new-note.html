5. 新建笔记

从一个模板目录复制骨架、清掉模板里的测试内容、按大纲生成章节、初始化 git。默认只预演。

面板入口创建与维护 → 卡片「新建笔记」→ 填名字与缩写 → 执行
命令行python tools/new_note/new_note.py

笔记名与缩写是必填；「只预演」默认勾着，先看它准备做什么。（点击图片用看图器放大）

什么时候用

  • 决定开始啃一本新书，要从模板建一本结构一致的笔记。
  • 手上已经有大纲（缩进清单或 md），想让工具一次性把章节骨架建出来。
  • 想确认「从模板到成书」到底会动哪些文件，先预演一遍。

怎么做

  1. 填笔记名（字母开头，可含数字下划线与连字符）与缩写（ASCII，例如 GT）。
  2. 有大纲就选文件；没有就留空，之后用大纲工具补。
  3. 保持「只预演」勾选，执行。看结果里的「将创建 / 将删除 / 将改写」清单。
  4. 确认无误，去掉「只预演」再执行一次。
  5. 需要远程仓库就勾「建好后推送」，但要先确保 manager.conf 里有远程账户名。

界面上每项的意思

项说明
笔记名目录名与 \title 的来源。会拦 Windows 保留名（CON/NUL/COM1…）与尾部空格。
缩写用于封面与页眉的短标识，必须是 ASCII。
大纲文件可空。给了才生成章节骨架；格式见「大纲工具」页。
层级可空，例如 part,section。连跳两级会提示。
模板目录可空，默认 Template/Math-Note。
只预演，不写文件默认开启。这是安全阀，别在看清单之前关掉它。
骨架里建最外层导引 / 各级小结默认不建。导引与小结按项目约定默认注释，不占版面。
建好后推送到远程需要 gh 或已建好的空仓库。

命令行用法

python tools/new_note/new_note.py --dry-run --name General_Topology --abbreviation GT
python tools/new_note/new_note.py --name General_Topology --abbreviation GT \
    --outline 大纲.md --levels part,section

文件都在哪

内容位置
新建的笔记工作区下的 LaTeX_Notes/<笔记名>/
读的模板Template/Math-Note/（可在表单里改）
远程账户名manager.conf
装进新仓库的 pre-commit 钩子tools/check_sensitive/pre-commit
「只预演」是本工具唯一的保护措施 —— 去掉勾选后它会真的建目录、改文件、执行 git init。第一次用某本新笔记时，先把预演清单从头看到尾。

常见问题

Q：提示「笔记名不合法」

A：只允许字母开头，后面可跟字母、数字、下划线、连字符。中文名要先转成英文（GitHub 仓库名同样限制）。

Q：大纲里写了 \input{...}，为什么生成时被跳过？

A：工具会判重：同一文件已在别处 import 就不再插入。若确实要插两次，先在 md 里删掉重复项。

Q：建完编译报错，说 structure.sty 找不到

A：模板目录选错了，或模板被移动。检查表单里的「模板目录」，或看 Template/Math-Note/ 是否存在。

Q：能不能不建 git 仓库，只建目录？

A：可以手工复制模板，但会丢掉钩子安装与标题转义。建议还是走工具。

Q：生成的中文标题为什么带了反斜杠？

A：那是 LaTeX 转义：_、&、% 在 \title 里必须转义，否则编译失败。正常现象。
