3. 符号库管理

在模板与各笔记之间搬运符号定义、刷新 TeXStudio 补全、删除或新增记号。默认只预览，不写文件。

面板入口核心工具 → 卡片「符号库管理」→ 选操作 → 执行
命令行python tools/symbols/symbols.py

操作下拉决定这一趟做什么；「真正写入」不勾就只出清单。（点击图片用看图器放大）

什么时候用

  • 在某一本书里新加了 \newcommand，想合并回模板，让以后新建的笔记都能用。
  • 模板新增了符号，要同步分发到已有各本笔记的 structure.sty。
  • TeXStudio 里新符号显示为「未知命令」，需要刷新 custom.cwl。
  • 某个记号名想改或想删，又不想在 10 个文件里手工找。

怎么做

  1. 选操作（回填 / 分发 / 刷新补全 / 删除 / 提取 / 引入新记号 / 全套），执行。
  2. 先看清单：它列出哪个文件、哪一行、会怎么改。这一步不写任何文件。
  3. 确认无误后勾「真正写入」，再执行一次。
  4. 刷新补全后重开 TeXStudio，或在 TeXStudio 里「重新载入补全」。

界面上每项的意思

项说明
操作七选一。切换后才会出现对应的输入项。
要删除的符号名多个用空格分隔，不带反斜杠。
命令名 / 定义 / 注释「引入新记号」用。命令名只允许字母；定义里 % 必须转义成 \%。
覆盖同名已有定义默认关闭。开启后同名定义的旧内容会被替换。
真正写入不勾只预览。这一项是所有写操作的统一开关。

命令行用法

python tools/symbols/symbols.py --merge --write         # 回填
python tools/symbols/symbols.py --distribute --write    # 分发
python tools/symbols/symbols.py --cwl --write           # 刷新补全
python tools/symbols/symbols.py --drop Foo Bar --write
python tools/symbols/symbols.py --add-name orb --add-def "\operatorname{Orb}" --write

文件都在哪

内容位置
笔记根目录、模板路径、cwl 路径symbols.conf（便携：tools/symbols/）
提取档案symbols_extract.json（同一目录）
目录结构快照notes_tree.json（同一目录）
TeXStudio 补全%APPDATA%\texstudio\completion\user\custom.cwl
回填会修改模板的 structure.sty。模板是唯一真源，工具会在写之前留一份可回滚的备份；但备份不是版本控制，改坏了请用 git diff 检查再决定。

常见问题

Q：只预览时显示「将新增 3 个符号」，勾了写入却没生效？

A：检查是否选对了操作。回填是「笔记 → 模板」，分发是「模板 → 笔记」，方向反了就看不到变化。

Q：提示「跨行定义无法解析」

A：\newcommand{\x}[2]{% 这种换行续写的写法，旧版本只认首行。现在整段解析，若仍报错，多半是续行里有未转义的 % 或括号不配对。

Q：分发后编译报 undefined control sequence

A：说明笔记的 structure.sty 里没有这个宏。常见原因是分发时该书的文件被 TeX 占用（编译中），写入失败但没报出来。关掉编辑器再分发一次。

Q：TeXStudio 里还是提示未知命令

A：补全文件路径可能不是这个 TeXStudio 用的那份。看工具输出里显示的 cwl 路径，与 TeXStudio 的「配置 → 补全 → 用户补全文件」是否一致；另外 cwl 是启动时读的，必须重启。

Q：删除符号会不会把模块 II–V 的同名宏一起删掉？

A：不会，只在 [模块 VI]（自定义符号段）里匹配。
