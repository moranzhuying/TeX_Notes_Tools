# git_setup.py

Git 基本信息的首次配置：检测环境、设置全局账户、配置 SSH。三项都作用于全局（`git config --global` 与 `~/.ssh/`），与具体笔记仓库无关。

## 运行

```bash
python git_setup.py
```

不带命令行参数，全部操作在面板里完成；总面板选项 1 进入的就是这个界面。

## 面板

```
==============================================================
  Git 基本信息设置
==============================================================
  1. 检测环境（git 安装 / 用户配置 / SSH 密钥 / 远程连通性）
  2. 配置 Git 账户（用户名、邮箱）
  3. 配置 SSH（生成密钥 / 写 config / 显示公钥 / 测试连通）
--------------------------------------------------------------
  0. 退出
==============================================================
```

可多选，用英文逗号分隔（如 `1,3`）；回车或 `0` 退出，每项做完按回车回面板。

| 选项 | 做什么 | 会改什么 |
|---|---|---|
| 1 | 报 `git --version`、全局 `user.name` / `user.email`、`~/.ssh` 下的 `*.pub`、`~/.ssh/config` 是否已指向 `ssh.github.com:443`，最后跑一次 `ssh -T git@github.com` | 不改任何文件 |
| 2 | 显示当前全局用户名与邮箱，逐项询问新值，回车保持不变 | `git config --global` 的 `user.name` / `user.email` |
| 3 | 配置 SSH，见下 | `~/.ssh/id_ed25519`（含 `.pub`）、`~/.ssh/config` |

## 选项 3 的动作

1. `~/.ssh/` 不存在则以 `0700` 创建。
2. 没有 `id_ed25519` 时询问是否生成；确认后执行
   `ssh-keygen -t ed25519 -N "" -C <注释> -f ~/.ssh/id_ed25519`。
   注释取 `manager/manager.conf` 的 `account`，取不到用 `note`。
3. `~/.ssh/config` 里没有 `ssh.github.com` 时询问是否补上；确认后在文件末尾**追加**：

```
Host github.com
    HostName ssh.github.com
    Port 443
    User git
```

   这一段让 github.com 走 443 端口，22 端口不通时用它。
4. 打印 `id_ed25519.pub` 全文，供粘贴到 GitHub 的 SSH keys 页面。
5. 询问是否测试连通性。

## 注意事项

- 选项 1 判断连通性看输出里是否含 `successfully authenticated`，不看返回码：`ssh -T git@github.com` 认证成功时返回码也不是 0。
- 选项 2 只改全局配置，不动仓库级配置；两个输入都留空则提示未作改动。
- 选项 3 不覆盖已存在的 `id_ed25519`；换密钥需自行处理旧文件。
- 写 `~/.ssh/config` 是追加，不是覆盖；已含 `ssh.github.com` 时整段跳过。
- 三项都是幂等的，重复运行不会重复生成密钥或重复追加同一段配置。
