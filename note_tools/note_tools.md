# note_tools.py

单本笔记的工具入口：先选一本笔记，再做提交推送、切换习题编排模式、或补导引与小结。

## 运行

```bash
python note_tools.py
```

无命令行参数，全部操作在面板里完成；总面板选项 7。

## 笔记清单

笔记根目录优先取 `manager/manager.conf` 的 `root`（支持环境变量），没有配置或目录不存在时退回工作区下的 `LaTeX_Notes`。

列为可选的笔记须满足：子目录、含 `main.tex`、名字不以 `.` 或 `_` 开头、不含 `Archieved`、且不在 `manager.conf` 的 `ignore` 名单里。每本后面标出 `git status --porcelain` 的条目数，用于看有没有未提交改动。

## 面板选项

选定笔记后：

| 选项 | 作用 | 会改什么 |
|---|---|---|
| 1 | 在该笔记目录里运行它自己的 `commit.py` | 由 `commit.py` 决定 |
| 2 | 在该笔记目录里运行它自己的 `setup_mode.py` | 由 `setup_mode.py` 决定 |
| 3 | 补导引与小结 | 见下 |
| 0 | 返回笔记清单 |

选项 1、2 只是**换到笔记目录里启动**对应脚本：这两个脚本依赖同目录的 `.git` 与 `Content/`，必须在笔记目录内运行。笔记里没有该脚本时直接报错返回。

## 补导引与小结

先选范围：`1` 导引＋小结（默认）、`2` 只加导引、`3` 只加小结。

规则复用 `new_note.py` 的 `add_intro_summary()`，与新建笔记时生成的完全一致：

- 层级模式按笔记现状推断，不从目录名或标题文字猜：优先用 `main.tex` 与正文里实际出现过的章节命令，对不上层数时按「层数 → 惯例起点」套用。
- **导引**只加在最外层，每章一个 `intro.tex`。
- **小结**加在所有会产生目录的层：每层一个 `Summary/`（`index.tex` ＋ `intro.tex` ＋ `01_summary.tex`）；末层是 `.tex` 文件时不加。
- 对应的 `\input` 插进该层 `index.tex`：导引插在第一条 `\input` 之前，小结插在附录之前（没有附录就接在最后一条 `\input` 之后）。
- **只补缺、不覆盖**：已存在的文件与已存在的 `\input` 行都跳过，可以反复跑。

流程是先干跑后落盘：先统计并列出将新建的文件、将改动的 `index.tex`，答 `y` 才写入；写入后提示这些改动尚未提交。

## 注意事项

- 选项 3 只处理 `Content/` 下已有的结构；`Content/` 不存在或没有正文 `.tex` 时报错退出。
- 补出来的是空骨架（每份留一行 `%` 注释说明该写什么），正文仍需自己填。
- 选项 3 的写入不经过 `commit.py`，不会自动提交。
